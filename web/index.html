      GitHub App

      Estado do App que entrega os eventos do GitHub à fábrica. Só leitura: nada é alterado no GitHub por esta tela.

          Como ligar o App

          O painel lê o App com a chave privada do arquivo indicado em FACTORY_GITHUB_APP_PRIVATE_KEY_PATH, junto com FACTORY_GITHUB_APP_ID (o número do App). Para o receptor, defina FACTORY_WEBHOOK_PORT e FACTORY_GITHUB_WEBHOOK_SECRET, e aponte um túnel para essa porta. Depois reinicie o daemon.

          Repositórios monitorados

          Pluga ou desplugua repositórios já configurados no YAML do projeto. Desplugar cancela as Tarefas ainda não iniciadas do repositório; uma Tarefa em execução pede confirmação antes.

            Nenhum repositório monitorado. Configure um projeto com source.type: github no YAML e reinicie o daemon.

            Monitorar um repositório novo

            A fábrica só conhece repositórios configurados no YAML do projeto (~/.config/software-factory/projects/<projeto>.yaml). Crie o projeto com um bloco source do tipo github, reinicie o daemon e depois plugue o repositório aqui.

            Publicações de retrô

            Repositório GitHub público onde as sugestões aprovadas viram issues. Salvar não publica nada: cada proposta continua exigindo revisão e aprovação.

            Vale sem reinício e substitui o valor inicial de FACTORY_RETRO_REPO.
